# TOUCH THE SKY

A simple website where you save problems you're stuck on.

## Features
- Save problems.
- Attach images.
- Dark mode.
- Export text as a `.txt` file.
- Import and export data.

## Technologies
- HTML
- CSS
- JavaScript

## Usage
1. Open `index.html` in your browser.
2. Write a problem.
3. Click Save Problem.
4. Use the other buttons to manage your problems.
